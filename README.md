# ClipNotify 剪贴提示

复制东西时总担心"Ctrl+C 到底复制上没有"？这个小工具在剪贴板变化时右下角弹个小浮窗 + 响一声，立即告诉你复制成功了。

## 特点

- **8 种提示音音色**：清脆叮 / 柔和叮 / 叮咚两声 / 三音上行 / 玻璃音 / 双音升调 / 风铃 / 马林巴琶音，右键点选即试听
- **音量 1-10 无级可调**：不再是三档，右键滑到合适音量就行
- **精确模式**：只有真按 Ctrl+C 才提示，微信划词等其他剪贴板写入不会误报
- **浮窗和提示音可单独开关**：有时候只要声音不要弹窗，或反过来
- **免安装、免联网、不接管剪贴板**：和 Ditto / CopyQ 等剪贴板管理器不冲突
- **仅 ~30KB**：开机放启动文件夹就行
- **日志开关**：默认不写日志，需要排查时右键打开

## 下载

进 [Releases 页](https://github.com/newilux/clipnotify/releases) 下载最新的 `clipnotify.exe`，双击运行即可。

首次运行若 SmartScreen 拦截，点"更多信息 → 仍要运行"即可（未签名小程序，自己写的代码可看源码）。

## 开机自启

把 `clipnotify.exe` 的快捷方式放到启动文件夹：`Win+R` 输入 `shell:startup` 回车，把快捷方式扔进去。

## 系统要求

Windows 7 及以上（自带 .NET Framework 4.x，无需额外安装运行时）。
